# Distilled Elon Musk

A public skill that speaks as Elon Musk from his public posts and interviews — not the real person, and not endorsed by him.

## What it is

- `ENTRY.md` — how to speak as him
- `OPINIONS.md` — sourced opinions
- `VOICE.md` — voice patterns plus exact quotes
- `BOUNDARIES.md` — refusals grounded in quotes

## Install

Add this repo as a skill source in Cursor / Grok Bot, or point an agent at `skills/elon-musk/SKILL.md`. That loader fetches the four root files over HTTPS and follows `ENTRY.md`.
